# Staff reading
Mode: Operate. Extend the existing practice room with treble-clef guitar pitch reading, preserving the user's typed-answer/Enter preference and progressive levels.

## Direction contract
THESIS: Connect a written note with its name and real guitar location through small recall rounds.
OWN-WORLD: Inherit Practice room's fonts, yellow paper, purple actions, lavender prompt and tier navigator, mint reference and pink guitar guide. Use self-hosted Bravura only for musical symbols.
STORY: Explore familiar C/D/E, read six notes, see results and guitar positions, then repeat or progress. Hide reference answers during the quiz.
FIRST VIEWPORT: Shared navigation and heading, existing two-column tool layout, central large five-line staff with treble clef, typed answer and stable actions. Sidebar carries tier progress and reference material.
FORM: Established-world tool extension; no new visual direction seed. Twelve levels cover lines/spaces, ledger lines and accidentals. Keep written pitch and sounding guitar pitch separate; ledger lines and musical glyphs use deterministic geometry.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
